# genealogy

Веб-приложение на Streamlit для анализа академических родословных, научных школ, тематических профилей диссертаций и публикационной активности.

## Источник данных

Единственный рабочий источник данных сайта — SQLite-база `genealogy.db` в корне репозитория.

Основные таблицы текущей базы:

- `diss_metadata` — метаданные диссертаций;
- `diss_scores_5_8` — тематические профили диссертаций для педагогических наук, 5.8.x / 13.00.xx;
- `diss_scores_2_3` — тематические профили диссертаций для информационных технологий, 2.3.x / 05.13.xx;
- `articles_metadata` — метаданные статей;
- `article_authors` — нормализованные сведения об авторах статей, их порядке, аффилиациях и географии;
- `article_keywords` — нормализованные ключевые слова статей с сохранением порядка;
- `articles_scores_inf_edu` — тематические профили статей.

Связь статей строится по ключу `Article_id`: он присутствует в `articles_metadata`, `article_authors`, `article_keywords` и `articles_scores_inf_edu`. Вкладка «Анализ статей (демо)» объединяет `articles_metadata` с `articles_scores_inf_edu`, а расширенные таблицы `article_authors` и `article_keywords` использует для метрик по авторам школы, аффилиациям, городам и ключевым словам.

CSV-файлы не используются runtime-кодом приложения как источник данных. Экспорт результатов пользователем в CSV/XLSX при этом остаётся штатной функцией интерфейса.

UI тематических сценариев поддерживает выбор двух диссертационных тематических профилей: педагогического `pedagogy_5_8` и ИТ-профиля `it_2_3`.

Формальные сценарии анализа поддерживают мягкий фильтр по отраслям наук: педагогические, психологические, философские, технические, физико-математические. Фильтр ограничивает состав диссертаций, но не меняет выбранный тематический классификатор.

Подробнее: [docs/sqlite_data_source.md](docs/sqlite_data_source.md).

## Локальный запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run streamlit_app.py
```

По умолчанию приложение ищет базу данных по пути:

```text
genealogy.db
```

Если база находится в другом месте, задайте переменную окружения:

```bash
SQLITE_DB_PATH=/путь/к/genealogy.db streamlit run streamlit_app.py
```

## Структура проекта

- `streamlit_app.py` — точка композиции Streamlit-приложения;
- `core/` — общий код приложения: доступ к данным, граф родословной, общие UI-компоненты, классификаторы;
- `tabs/` — независимые пакеты функциональности отдельных вкладок;
- `docs/` — архитектурная и эксплуатационная документация;
- `genealogy.db` — публичная SQLite-база данных сайта.

## Правила разработки

- Runtime-доступ к данным должен проходить через `core/db/`.
- Вкладки не должны напрямую читать файлы данных; исключение для статических справочных JSON должно оформляться через общий слой `core/`, как в `core/source_schools/`.
- Публичные комментарии, строки документации и пользовательские сообщения в затрагиваемом коде пишутся на русском языке.

### Школы по источникам

Раздел читает шесть школ из нативных JSON v2.1 в `data/source_schools/schools/`. Общие фильтры работают в режимах «Дерево», «Таблица» и «Вместе»; основное деление необязательно, число гибких измерений произвольно. Каталог поддерживает метки стран и языков работ. Подробнее — в [документации](docs/source_schools_demo.md).

У каждой школы и карточки персоны есть постоянная ссылка. Имя открывает карточку в контексте школы в новой вкладке браузера; отдельная SVG-иконка открывает имеющееся дерево научного руководства. Доступность дерева проверяется по однозначной идентификации и реальным записям базы. Состав школы по источникам не создаёт диссертационных связей. Поддерживаются JSON, CSV, XLSX, TXT, HTML, PNG и ZIP; полный экспорт сохраняет исходный документ.

В `diss_metadata` добавлены 74 исторические записи диссертантов круга Выготского с кодами `mn20261010001_vc`–`mn20261010074_vc`. Импортированный набор сохранён для проверки в `data/manual_imports/vygotsky_circle_20261010.csv`; runtime-приложение продолжает читать SQLite.
