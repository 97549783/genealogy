# Количественные метрики научного руководства

Блок метрик рассчитывается для уже построенного и показанного графа научного руководства. Рёбра направлены как «научный руководитель → диссертант». Значения учитывают выбранный корень, фильтр отраслей наук и выбранный тип дерева.

## Правила для графов с несколькими руководителями

Каждый потомок считается один раз. Если от выбранного руководителя до одного потомка есть несколько путей, поколение определяется по кратчайшему пути. Значения относятся только к текущему отфильтрованному и отображаемому графу. Это позволяет корректно считать показатели для случаев совместного научного руководства.

Для пересекающихся ветвей потомок закрепляется за первой достижимой ветвью первого уровня в детерминированном лексикографическом порядке. Это правило используется для баланса ветвей, доли крупнейшей ветви и метрик продолжения ветвей.

## Используемые обозначения

- `r` — выбранный руководитель;
- `V_r` — множество участников текущего отображаемого графа, достижимых из `r`;
- `E_r` — множество связей научного руководства в текущем отображаемом графе;
- `Ch(v)` — множество прямых учеников участника `v`;
- `Desc(r)` — множество всех потомков `r` без самого `r`;
- `g(v)` — поколение участника `v`, то есть кратчайшее расстояние от `r` до `v`;
- `W_k` — число участников `k`-го поколения;
- `W_1` — число прямых учеников;
- `W_2` — число потомков второго поколения;
- `y(v)` — год защиты участника `v`;
- `n_t` — число новых потомков в году `t`;
- `P(t)` — накопленное число потомков к году `t`.

## Основные термины и формулы

- **A-score / плодовитость / fecundity**: `A(r)=|Ch(r)|`. Показатель равен числу прямых учеников выбранного руководителя.
- **Фертильность / fertility / 1-fertility**: `ft+(r)=|{u: (r,u) in E and f+(u)>0}|`. Показатель равен числу прямых учеников, которые сами стали научными руководителями.
- **Доля продолжателей**: `ft+(r) / f+(r) * 100%`. Показатель нормирует фертильность на число прямых учеников.
- **T-score / descendants**: все уникальные достижимые потомки выбранного руководителя во всех поколениях.
- **G-score / generations**: максимальное расстояние от корня до потомка; при нескольких путях используется кратчайший путь.
- **Уровней с корнем**: `G(r)+1`; корень учитывается как уровень 0. Метрика доступна в таблицах и справке, но не является обзорной карточкой.
- **W-score / максимальная ширина поколения**: максимальное число потомков в одном поколении; при равенстве выбирается самое раннее поколение.
- **Среднее число всех потомков на прямого ученика**: `|Desc_{>=2}(r)| / W_1`. Показывает, сколько потомков второго и следующих поколений в среднем приходится на одного прямого ученика.
- **Среднее число потомков второго поколения на прямого ученика**: `W_2 / W_1`. Показывает ближайшее продолжение научного руководства через прямых учеников.

## Академическая пролиферация

Для потомков с валидным годом защиты строится ряд новых и накопленных потомков по календарным годам. Годы без новых потомков между первым и последним наблюдаемым годом сохраняются в ряду с нулевым приростом. Liénard et al. используют proliferation rate как среднее число подготовленных исследователей за десятилетие; в приложении дополнительно показывается среднее число новых потомков за календарный год в наблюдаемом периоде.

## Дополнительные метрики

Дополнительные показатели помогают интерпретировать ветвление, форму дерева, состав и динамику: терминальные и внутренние потомки, среднее и медианное ветвление, максимальное локальное ветвление, среднее поколение потомков, нормированная глубина, баланс ветвей первого уровня, доля крупнейшей ветви, медиана всех потомков в ветви, медиана потомков 2-го поколения в ветви, структурный h-индекс линии, индекс линейности, период активности, год пикового роста, максимальный неактивный разрыв, недавняя активность за пять лет и состав по уровню степени.

Медиана всех потомков в ветви считается как `median(b_{>=2}(c): c in Ch(r))`, где `b_{>=2}(c)` — число закреплённых за прямым учеником потомков второго и следующих поколений. Медиана потомков 2-го поколения в ветви считается как `median(b_2(c): c in Ch(r))`.

## Технические показатели качества данных

Технические показатели остаются в расчёте для диагностики, но по умолчанию не показываются в пользовательской панели, сводной таблице и экспорте.

## Ограничения

Цикл в достижимой части графа делает метрики поколений, ширины и динамики недоступными, но базовые структурные счётчики сохраняются. Неоднозначные нормализованные имена отмечаются предупреждением, а для временного анализа выбирается самый ранний валидный год.

## Пример

Для графа `Корень → A`, `Корень → B`, `A → C`, `C → D` прямых учеников будет 2, учеников-продолжателей 1, потомков 4, поколений потомков 3, уровней с корнем 4, максимальная ширина 2 в первом поколении, среднее число всех потомков на прямого ученика 1, среднее число потомков второго поколения на прямого ученика 0,5.
