# Школы по источникам (демо)

Раздел показывает, как состав и структура научной школы могут описываться по опубликованным источникам. Он не вычисляет принадлежность к школе из научного руководства, не обращается к `genealogy.db` и не изменяет базу данных.

## Чем отличается от генеалогических школ

Генеалогические разделы строятся вокруг связей научного руководства. Этот демо-раздел хранит источниковые атрибуции: один источник может назвать участника учеником, другой — сотрудником или представителем круга. Интерфейс показывает эти формулировки отдельно и помечает нормализованные роли как систематизацию.

## Каталог данных

Файлы располагаются в каталоге `data/source_schools/`. Runtime-чтение этих статических справочных файлов вынесено в общий слой `core/source_schools/`, поэтому вкладка Streamlit не открывает JSON напрямую. Каждый файл должен быть UTF-8 JSON и иметь верхние блоки:

- `школа`;
- `демо_представление`;
- `контроль_качества`;
- необязательный служебный блок `_processing_metadata`, который интерфейс не показывает.

Идентификатор школы берётся из `школа.идентификатор_школы`, а подпись в выпадающем списке — из `демо_представление.название_в_выпадающем_списке`. Значения должны быть непустыми и уникальными в каталоге.

## Проверка связности

Загрузчик проверяет уникальность идентификаторов персон, источников, подтверждений и исследовательских групп. Также проверяются ссылки из персон, источниковых атрибуций, подтверждений, групп, направлений, поколений, хронологии и историографических позиций. Значения уверенности должны быть числами от `0` до `1`. Сводные показатели пересчитываются по данным и сравниваются с блоками `демо_представление.сводные_показатели` и `контроль_качества`.

## Как добавить школу

1. Подготовьте новый JSON-файл с той же общей структурой.
2. Поместите файл в `data/source_schools/`.
3. Убедитесь, что идентификатор школы и название для выпадающего списка не повторяются.
4. Запустите проверку:

```bash
pytest -q tests/test_source_schools_data.py tests/test_source_schools_tables.py tests/test_source_schools_tab.py
```

После успешной проверки новая школа появится в выпадающем списке без изменения кода интерфейса.

## Ограничения MVP

Раздел не поддерживает редактирование JSON через интерфейс, загрузку файлов пользователем, автоматическое извлечение фактов из публикаций, графовую визуализацию, экспорт таблиц и сопоставление персон с диссертационными записями.

## Обновление требований к демонстрации школ по источникам

Раздел использует подготовленный JSON `data/source_schools/vygotsky_school_sources_demo.v1.json`. Для каждой персоны обязательно реальное имя в поле `имя` или `полное_имя`; placeholder-записи вида `Представитель N`, `Участник N`, `Person N` и демонстрационные описания вклада запрещены валидатором. Источники должны содержать поле `библиографическое_описание`; краткие технические идентификаторы источников не выводятся пользователю.

В режиме «Источники и подтверждения» первым показывается нумерованный список использованных источников. Нумерация следует порядку JSON или полю `порядок`, если оно задано для всех источников. Описание берётся из `библиографическое_описание`; DOI, URL и дата обращения добавляются только при отсутствии дубля в исходном описании. Формат описывается как близкий к ГОСТ, без заявления о сертифицированной автоматической проверке.

В режиме «Обзор» дерево отражает структурную систематизацию представителей по поколениям и источниковым категориям. Оно не является деревом научного руководства и не создаёт неподтверждённые отношения «учитель — ученик» между персонами.

Поддерживаются выгрузки JSON, CSV, XLSX, TXT, HTML, PNG и ZIP. Полный ZIP содержит исходный JSON, книгу Excel, CSV по представителям, источникам, подтверждениям и рёбрам дерева, текстовый список источников, PNG дерева и интерактивное HTML-дерево.

При добавлении новой школы нужно подготовить JSON без placeholder-данных, указать реальные библиографические описания, проверить ссылки персон, источников, подтверждений, групп, направлений и поколений, а затем выполнить:

```bash
pytest -q tests/test_source_schools_data.py tests/test_source_schools_tables.py tests/test_source_schools_bibliography.py tests/test_source_schools_tree.py tests/test_source_schools_export.py tests/test_source_schools_tab.py tests/test_streamlit_app_smoke.py
pytest -q
```
